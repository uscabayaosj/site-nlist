# NLIST — Enrollment system for board exam review schools

Product site: [uscabayaosj.github.io/site-nlist](https://uscabayaosj.github.io/site-nlist)

Built for schools with two intake cycles per year. Replaces Google Form + Google Sheet enrollment with a purpose-built portal.

## Design

Fraunces + Inter on a light blue-grey background with navy blue accents — same design language as the other ainsight product sites.
